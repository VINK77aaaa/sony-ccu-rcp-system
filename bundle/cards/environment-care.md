# 使用环境与保养红线 (RCP-3500/3501)

## R — 原文

- 冷凝（第 3 页）：成因是温差（突然从寒冷地方带到温暖场所，或室温突然升高）；处置为 "关闭设备电源,待到冷凝消失后才能操作"；"冷凝仍然存在时使用可能导致设备损坏"。
- 电磁干扰（第 3 页）：原文为 "建议" 级——"建议将…电源关闭"（本机附近的便携式通信设备）；在附近使用可能 "造成故障并干扰音频和视频信号"。
- 电解电容（第 3 页）：预计寿命 "约为 5 年"，基准工况 "每天 8 小时;每月 25 天"；超出基准则寿命相应减少。
- 网络安全（第 3 页）：连接网络前 "必须确认网络有安全保护"；否则未授权第三方可能访问，损坏厂商免责。
- 医疗设备（第 3 页）：勿将本产品放在医疗设备使用者附近（干扰对象含心脏起搏器/可编程分流阀）；自身使用者使用前咨询医生。
- 清洁触控面板（第 3 页）：柔软干布轻擦脏污区；不可用薄纸用力擦（可能划伤涂层）；污渍顽固先轻轻除尘再擦。
- LCD 故障像素（第 3 页）：有效像素率 "至少达到 99.99%"，这类问题 "并非故障"。
- 使用义务（第 56 页）："在使用前请始终确认本机运行正常"；任何损坏/利润损失等厂商概不负责。

## I — 自述

这是一张**清单卡**：把注意事项页（第 3 页）与许可证页义务（第 56 页）整理成"七条红线 + 一条使用义务"，每条按"触发 → 动作 → 后果"执行。

要点不在背条目，而在**分清语气等级**：

- **强制级**（手册用"必须/勿"）：冷凝必须断电等消失；接网前必须确认网络安全；勿放医疗设备使用者附近；
- **建议级**（手册用"建议"）：本机附近的便携通信设备建议关机——不得把"建议"升格为"禁止"；
- **口径级**（给数值基准而非禁令）：电容寿命约 5 年按特定工况推算，超基准方向性折减（无换算公式）；LCD 坏点 99.99% 有效像素率内属正常，不报修。

另一条义务是"使用前确认运行正常"——在厂商免责的语境下，这是操作方的自保动作，落地手段是每日灯语自检。

## A1 — 合成演练

**原书未提供案例**（注意事项章节为禁令/警告条目，无过程性示例）。以下为**合成演练**（按 p01/f34 规则可复算）：输入 = 冬季面板从寒冷车辆搬入温暖机房，外壳与屏幕起雾 → 执行 = 判定冷凝 → 立即关闭电源 → 等待冷凝完全消失（可观察判据：外壳与屏幕雾退）→ 预期 = 消失前不通电、不操作（后果：冷凝存在时使用可能导致设备损坏）；消失后恢复正常使用。

## A2 — 未来触发

**情境**：

1. 搬运/进场/季温差："设备从车上搬进来屏幕起雾了，还能开机吗"。
2. 安装选址：机房位置邻近医疗设备使用者，或操作员身边常开手机/对讲机。
3. 日常保养："触控屏脏了怎么擦 / 能不能用纸巾使劲擦"。
4. 维护计划："电容几年换一次 / 7×24 连续用寿命怎么算"。
5. 接网/开播前检查："接入这个网段安全吗 / 今天投用前要检查什么"。

**语言信号**：中文——"冷凝 / 起雾 / 结雾 / condensation / 清洁 / 擦屏幕 / cleaning / 电容 / 寿命 / lifespan / 干扰 / 手机 / interference / 起搏器 / 医疗设备 / 网络安全 / 坏点 / 亮点 / dead pixel / 使用前检查"；英文——"condensation / cleaning / lifespan / interference / medical device / network security / dead pixel / before use check"。

**相邻区分**（初稿，阶段 3 回填）：

- **led-diagnostics**：坏点/白点判为"非故障"后的灯语排障与"要不要报修"甄别流程在彼卡；本卡只断言红线本身（99.99% 口径、白点物理特性）。
- **network-setup**："确认网络安全"的执行点在组网流程（彼卡步骤 2）；本卡收录红线与后果（厂商免责、损失自担）。
- **specs-reference**：电容寿命等数值的原样速查在彼卡；折减决策与保养计划在本卡。
- **maintenance-correction**：Shading/RPN 等校正维护在彼卡；本卡是环境与保养红线，不做参数校正。
- **daily-operation**：每日画质类开机流程在彼卡；本卡的"使用前确认"仅指环境红线核对与灯语自检转介。

## E — 执行步骤

**输入契约**（缺失先问）：当前情境类型——搬运温差 / 安装选址 / 清洁 / 维护计划 / 接入网络 / 投入使用。情境不明先问，不猜。

**清单执行**（命中即执行，逐条给出"命中/未命中 + 动作 + 页码"）：

1. **冷凝（强制）**：温差后外壳/屏幕起雾 → 关闭电源，待冷凝完全消失后才能操作；未消失即使用可能损坏设备（第 3 页）。**判停**：消失前唯一动作是等待，无旁路。
2. **电磁干扰（建议级，语气不得升格）**：本机附近使用便携通信设备可能造成故障并干扰音视频 → 建议关闭其电源；出现不明滚纹/噪点时先列入干扰怀疑项（第 3 页）。
3. **电容寿命（口径）**：基准 "每天 8 小时;每月 25 天" → 约 5 年；超基准工况寿命相应减少 → 维护计划按工况折减提前；换算公式原书未给，不推算数值（第 3 页）。
4. **医疗设备（强制）**：不放置在医疗设备（心脏起搏器/可编程分流阀等）使用者附近；自身使用医疗设备者先咨询医生（第 3 页）。
5. **网络安全（强制）**：接入网络前必须确认网络有安全保护；未确认不接入（第 3 页）。执行点与组网步骤转 network-setup。
6. **清洁（方法）**：柔软干布轻擦脏污区；不用薄纸用力擦；污渍顽固先轻轻除尘再擦（第 3 页）。**判停**：手边只有纸巾 → 不执行清洁，等软布。
7. **LCD 坏点（口径）**：有效像素率至少 99.99%，固定亮点/闪烁像素属正常物理特性，不作为故障报修（第 3 页）。
8. **使用义务**："在使用前请始终确认本机运行正常"（第 56 页）→ 每日投用前过一遍灯语自检（转 led-diagnostics）；未确认不投入正式使用。

**输出契约**：逐条结论 = 命中/未命中 + 动作 + 页码；强制/建议/口径三级语气原样保留，不混用。

## B — 边界

- **不要用本卡**：灯语判读（led-diagnostics）、组网与接地操作（network-setup）、校正类维护（maintenance-correction）、数值速查（specs-reference）。
- **失败模式（原书反例）**：冷凝未消失通电 → 设备损坏（ce01）；薄纸用力擦 → 划伤涂层（ce02）；附近用手机 → 故障与音视频干扰（ce03）；靠近起搏器使用者 → 干扰医疗设备（ce04）；7×24 工况仍按 5 年排电容更换 → 提前劣化（ce05）；接入无保护网络 → 第三方可能访问、损失自担（ce06）；亮点/白点误报修（ce34，两级处理见 led-diagnostics/maintenance-correction）。
- **手册边界（阶段 0 批判）**：电容 5 年按"每天 8 小时、每月 25 天"推算，其他工况无数据；LCD 允许坏点具体数量未给；仅 LAN 连接未接地的后果手册未明示（接地操作本身在 network-setup）；免责声明下"使用前确认"是责任自担的自保动作，手册未给确认清单。
- **型号差异**：本卡红线两款通用，不区分 RCP-3500/3501。
