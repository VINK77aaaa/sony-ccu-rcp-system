# 规格与接口速查 (RCP-3500/3501)

## R — 原文

- 电缆长度："使用 CCA-5 电缆从 CCU 到本机的最大连接长度为 200 m"；"使用 LAN 电缆从 PoE 兼容集线器到本机的最大连接长度为 100 m"。(第 16 页)
- 规格表（第 55 页）：电源 "10.5 V 至 17 V 直流"（适用于 EXT I/O 接口）；"PoE 36 V 至 57 V"（兼容 IEEE802.3af class 2）；功耗 10 W（包括 AUX 接口输出）；工作温度 5 °C 至 40 °C；存放温度 –20 °C 至 +60 °C；质量 1.7 kg。
- 针脚表选件（第 55 页）：EXT I/O 接口选件 JAE DE-9PF-N（型号 1-568-182-11）。
- Tally 限制：EXT I/O 的 TALLY 输入 "可在 LEGACY 模式或 BRIDGE 模式中使用。但在 MCS 模式中会被禁用"。(第 56 页)
- 线材：LAN 电缆须为屏蔽型 5e 类；PoE 集线器须兼容 "IEEE802.3af"。(第 15 页)
- 易耗件口径：电解电容预计寿命 "约为 5 年"，基准工况为 "每天 8 小时;每月 25 天"。(第 3 页)

## I — 自述

本卡是**查表卡**：把原书第 55-56 页的规格表与针脚分配表、第 15-16 页的线材/长度约束、第 3 页的易耗件口径原样收录，服务三个场景——施工备线（线材/长度/供电）、外部接口接线（针脚）、方案与维护核算（温度/质量/机架/寿命）。

使用纪律只有一条：**查询 → 原样回报，禁止换算**。数值、单位、适用条件、型号选件号一律照抄并标页码；需要判断时另做阈值比较（比较不改写原值）；表里没有的字段回答"原书未给"，不推算、不插值、不"约等于"。

随附限制必须一起提示：TALLY 输入仅 LEGACY/BRIDGE 可用（MCS 禁用）；主黑电平相关设定在 RCP-3501 上不存在。这两条是按表施工/排障时最容易踩的模式与型号坑。

## A1 — 合成演练

**原书未提供案例**（规格/针脚为查表内容，无过程性示例）。以下为**合成演练**（按阈值与表格可复算）：

1. 输入 = "CCA-5 想布 250 m 行不行" → 执行 = 查电缆长度条目 → 回报 = "最大连接长度为 200 m（第 16 页）" → 判定 = 250 m > 200 m，超上限，不在保证范围。
2. 输入 = "EXT I/O 针脚 8 是什么" → 回报 = "8 = POWER IN，10.5 V 至 17 V（第 56 页）"，并随附提示：TALLY 相关输入（针脚 5/6/7）在 MCS 模式禁用。

## A2 — 未来触发

**情境**：

1. 施工/采购："CCA-5 最长多少米 / 网线用什么样的 / 供电多少伏 / 功耗多少瓦"。
2. 接线施工："EXT I/O 针脚怎么定义 / Tally 从哪几脚进 / CALL OUT 能带多大电流"。
3. 机架与安装规划："面板多重 / 一个机架装几台 / 工作温度范围多少"。
4. 维护计划："电容几年一换 / 7×24 用寿命怎么算"。
5. 排障核对：怀疑超规（线太长、温度超限、非 PoE 集线器）时原样核对参数。

**语言信号**：中文——"规格 / 参数 / 针脚 / 接口 / 多少伏 / 多少米 / 功耗 / 重量 / 寿命 / 规格表"；英文——"specs / specification / pin assignment / pinout / cable length / power supply / dimensions / weight"。

**相邻区分**（初稿，阶段 3 回填）：

- **network-setup**：拿数值做组网/施工决策（选模式、接地、布线方案）归彼卡；本卡只"查询→原样回报"，不做方案判断。
- **environment-care**：电容寿命的保养决策与红线归彼卡；本卡只给数值口径（"约 5 年"按每天 8 小时/每月 25 天基准）。
- **mcs-operations**："Tally 在 MCS 被禁用"的模式语境在彼卡/network-setup；本卡回报针脚数值时随附该限制提示。
- **led-diagnostics**：排障中灯语判读归彼卡；本卡只在其判读引用到线长/规格阈值时提供原样数值。

**步骤**：

0. **输入契约**（缺失先问）：要查的字段名（电压/长度/针脚号/寿命…）与用途（施工/接线/方案/排障）。字段不明先问，不猜。
1. **查表**：在上方两表及线材/长度/寿命条目中定位字段。
2. **回报**：格式 = `字段 = 原样数值+单位 (第 X 页)`；需要判定时另起一行做阈值比较（如 "120 m > 100 m → 超上限"），比较不改动原值。
3. **随附限制**：回报 Tally 相关针脚必附 "MCS 禁用"；回报主黑电平相关项必附 "RCP-3501 无主黑电平调节功能，该设定项不存在"（第 25 页）。
4. **判停**：表中无此字段（级联总长上限、工作湿度上限、完整默认网关值、外形尺寸细节等）→ 回答 "原书未给"，不推算、不插值。

**输出契约**：逐字段回报，每条带页码；判定类问题输出 "原值 + 比较 + 结论" 三段，原值零改写。

## B — 边界

- **不要用本卡**：组网决策与配置（network-setup）；环境保养动作（environment-care）；把数值"换算成更好懂的单位"——契约禁止换算。
- **失败模式**：把 "约 5 年" 当绝对寿命抄表——7×24 工况须折减提前，但换算公式原书未给（ce05）；按针脚表把 Tally 盲接进 MCS 系统 → 接入不工作（ce32，与 p66 配对）；在 RCP-3501 上找主黑电平调节灵敏度设定 → 设定项不存在，涉主黑电平先核型号（ce37）。
- **原书边界（缺口）**：级联总长上限未给；工作湿度上限未给；外形尺寸图为图形信息，文字仅保留关键毫米数；手册不含固件版本号对照；TCP/IP 画面默认网关示例提取乱码（仅尾段 254 可辨），不推测。
- **型号差异**：两型号共用同一张规格表；差异点仅在主黑电平相关设定（3501 不可用）与 PREVIEW 物理按钮（仅 3500 有，属日常操作）。
