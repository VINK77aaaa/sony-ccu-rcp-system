# 组网连接与配置 (RCP-3500/3501)

## R — 原文

- "更改连接模式 (CNS) 后,需重启所有摄像机系统。" (第 5 页)
- LEGACY: "使用 CCA-5 电缆连接摄像机控制单元 (CCU) 和 RCP"，该模式下 "TCP/IP 和 RCP 编号无需设定"；CCU 编号取值 1–96、A–Z。(第 5 页、第 18 页)
- BRIDGE: "使用 LAN 电缆连接 CCU 和 RCP (一对一)"；"在 BRIDGE 模式中,无法采用多摄像机操作"。子模式 Active / Passive / Semi-Auto（Semi-Auto 下：RCP 单独使用→Active；经 CCA-5 连 CCU/摄像机→Passive）。(第 5 页、第 18-19 页)
- MCS: "除了设定本机的 TCP/IP 设定和主设备的 IP 地址以外,还必须设定 RCP 编号"；"RCP 编号对应于 MSU 的摄像机选择编号"；"如果 RCP 编号重复, 则设备无法正常工作"。主设备可用 MSU-1500/1000 或 CNA-1；多台 MSU 时一台配主设备、其余配客户端。(第 19 页、第 7 页)
- 混合拓扑: "当使用 LAN 电缆连接本机,并使用 CCA-5 电缆连接CCU 时,请设定 MCS 模式。" (第 19 页)
- PC 控制: "使用 HZC-RCP5 摄像机远程控制软件配置"，"可连接最多六个 RCP 单元"。(第 6 页)
- 安装: 接地仅在 "只使用 LAN 电缆连接时" 必须，用 "长度不超过 10 mm" 的 M3 螺钉将安全接地线与控制面板底部相连；"使用 CCA-5 电缆从 CCU 到本机的最大连接长度为 200 m"；"使用 LAN 电缆从 PoE 兼容集线器到本机的最大连接长度为 100 m"。(第 16 页)
- 线材: LAN 电缆须为屏蔽型 5e 类；供电须来自 "IEEE802.3af 兼容" 的 PoE 集线器。(第 15 页)
- 接入前置: 连接网络前 "必须确认网络有安全保护"。(第 3 页)

## I — 自述

RCP 与摄像机系统怎么连，由一个叫 CNS 的连接模式决定，四选一，判据是物理连线与需求：

- 只拉 CCA-5 专用电缆 → LEGACY，唯一免配网络参数的模式；
- 只拉网线且一对一 → BRIDGE，要配本机 IP + 目标 IP（含 Active/Passive/Semi-Auto 子模式），但不支持多机操作；
- 网线连面板 + CCA-5 连 CCU 的混合拓扑，或多面板/MSU 多机系统 → MCS，要配本机 IP + 主设备 IP + RCP 编号；
- 由 PC 软件 HZC-RCP5 控制 → PC 控制，上限六个 RCP 面板。

三条铁律横跨所有模式：①系统内 IP 与 RCP 编号必须唯一；②更改 CNS 后必须重启所有摄像机系统（不是只重启本面板）；③纯 LAN 供电安装必须接地。施工硬约束：CCA-5 ≤200 m、LAN ≤100 m、屏蔽 5e 类线、IEEE802.3af PoE 集线器。所有连接设定在工程师模式中配置。

## A1 — 书中配置示例

以下均为**书中配置示例**（原书自带拓扑/画面示例值，非实际工程记录）：

1. LEGACY 拓扑（c01，第 5 页）：CCU（HDCU5000/5500/3500）与面板 CCA-5 直连，两端 CNS 均为 Legacy，CCU 编号取 1–96、A–Z，无任何 IP 设置项。
2. MCS 编址规律（c04，第 7 页、第 19 页）：MSU-1500 = 192.168.0.201（Master 设备编号 1）；CCU n ↔ 192.168.0.n；RCP m ↔ 192.168.0.(100+m)；各 RCP 的主机 IP 均填主设备 192.168.0.201，RCP 编号 = MSU 摄像机选择编号。
3. BRIDGE/TCP/IP 画面示例值（c05，第 19-20 页）：本机 IP 192.168.0.101 / 子网掩码 255.255.255.0，目标（CCU）192.168.0.1。（默认网关完整值原书画面提取乱码，仅尾段 254 可辨——如实标注，不推测。）
4. PC 控制编址（c03，第 6 页）：PC（HZC-RCP5）= 192.168.0.201、RCP 链接开；CCU 取 192.168.0.1/0.2/…且各记 PC IP，CCU 编号与 IP 尾段对应；面板以 CNS:MCS、主机 IP 192.168.0.201、RCP 编号 6 混合接入；上限六个 RCP。

## A2 — 未来触发

**情境**：

1. 新装/搬迁面板："这台 RCP 怎么接入系统 / 用什么模式 / IP 怎么填"。
2. 组网变更（加机位、Legacy 改 LAN、换主设备）后要投用或系统行为异常。
3. 施工/采购阶段：问线材规格、电缆能拉多长、要不要接地。
4. 安装检查单/验收：核对编号唯一性、IP 规划、接地、网络安全前置项。

**语言信号**：中文——"组网 / 连接 / 配 IP / 设 RCP 编号 / CNS / LEGACY / BRIDGE / MCS / 接地 / 网线怎么接 / 改了模式要不要重启"；英文——"network setup / connection mode / CNS / IP address / RCP number / grounding / LAN or CCA-5"。

**相邻区分**（初稿，阶段 3 回填）：

- **mcs-operations**：拓扑选型与配置步骤归本卡；MCS 建好后的激活仲裁（PANEL ACTIVE/PARA/IRIS-MB ACTIVE）、RCP Assign、主从归彼卡。问"怎么配 MCS"→本卡；"配好了但拧不动/谁有控制权"→彼卡。
- **led-diagnostics**：配置完成后 NETWORK 等灯语判读归彼卡；本卡负责把配置改对。
- **specs-reference**：线材/长度/电压纯数值速查归彼卡（禁止换算）；拿数值做组网决策归本卡。
- **environment-care**：网络安全"必须确认"红线收录在彼卡清单，执行点在本卡步骤 2。
- **engineer-mode-security**：连接设定须在工程师模式中配置，进入/退出流程归彼卡。

## E — 执行步骤

**输入契约**（缺失先问，不猜）：①物理连线——面板与 CCU 各用什么电缆（CCA-5 / LAN / 混合）；②需求——是否多机位/多面板，有无 MSU/CNA-1 或 HZC-RCP5；③LAN 时的 IP 规划——本机 IP/子网掩码、目标 IP 或主设备 IP、RCP 编号；④所连 CCU/摄像机是否在支持清单（第 8 页）。拓扑或 IP 不明 → 先询问，不得静默猜值。

1. **模式决策**（输出唯一归类）：
   - 只用 CCA-5 → LEGACY（跳 3a）；
   - LAN 一对一且无多机需求 → BRIDGE（跳 3b）；
   - LAN 连本机 + CCA-5 连 CCU，或多机/MSU 系统 → MCS（跳 3c）；
   - HZC-RCP5 PC 控制 → 决策层确认上限 ≤6 台 RCP；**判停**：面板侧配置步骤原书未给，转 HZC-RCP5 文档，不代配。
2. **接入前置检查**（任一不过即停）：网络安全保护已确认（未确认不接入，第 3 页）；LAN 线 = 屏蔽型 5e 类，PoE 集线器兼容 IEEE802.3af；CCA-5 ≤200 m、LAN ≤100 m；纯 LAN 连接 → 用 ≤10 mm 的 M3 螺钉将安全接地线接面板底部。
3. **配置**（MENU → Config → RCP → Network；须在工程师模式中，进入方法见 engineer-mode-security）：
   - a. LEGACY：Network → CNS → Legacy → [Set]。完成判据：出现"控制面板已设为 LEGACY 模式"；全程无网络参数输入项。
   - b. BRIDGE：CNS → Bridge → [Set] → [Edit] 选子模式（RCP 单独用→Active；经 CCA-5 连着 CCU→Passive；拿不准选 Semi-Auto）→ 设目标 IP → [Exit]×2 → 设本机 TCP/IP（IP/子网掩码）→ [Exit]。对端（CCU）侧须把本机配置为设定目标。
   - c. MCS：CNS → MCS → [Set] → 本机 TCP/IP → 主设备 IP → RCP 编号（= MSU 摄像机选择编号）。完成判据：走完八步回到 Network 画面。
4. **唯一性复查**：全系统 IP、RCP 编号无任何重叠（编号重复 → "设备无法正常工作"）。
5. **收尾铁律**：重启**所有摄像机系统**；未重启不投入使用。

**判停分支**：完成后 NETWORK 灯闪烁/仍不通 → 先查物理链路与 IP/编号（灯语判读转 led-diagnostics）；MCS 建好后的操作仲裁问题 → 转 mcs-operations。

**输出契约**：报告 = 选定模式 + 配置路径 + 关键参数（IP/掩码/编号原样）+ 已执行的前置检查与重启项清单。

## B — 边界

- **不要用本卡**：灯语判读（led-diagnostics）、面板激活/PARA/RCP Assign 仲裁（mcs-operations）、规格数值速查（specs-reference）、工程师模式进入流程（engineer-mode-security）。
- **手册警告的失败模式**：改 CNS 后不重启所有摄像机系统（ce07）；RCP 编号/IP 重叠 → 设备无法正常工作（ce13）；用 BRIDGE 承载多机需求 → 无法采用多摄像机操作（ce14）；仅 LAN 连接不接地（ce15）；固件非最新或设备不在支持清单 → 功能可能无法正常工作，排障先核这两项（ce08）；接入无安全保护的网络 → 未授权第三方可能访问、损失自担（ce06）；MCS 下 EXT I/O 的 TALLY 输入被禁用，施工图勿按针脚表盲接（ce32，数值见 specs-reference）。
- **型号差异**：RCP-3500 与 RCP-3501 组网规则完全一致，本卡不分型号。（PREVIEW 物理按钮仅 RCP-3500 有，属日常操作范畴，不在本卡。）
