# Web 菜单远程运维 (HDCU5000/5500/3500)

## R — 原文

- 访问 Web 菜单: "建议使用 Chrome。使用除 Chrome 外的其他网络浏览器,可能会破坏网页菜单的布局,或导致某些功能无法正常运行。" (第 20 页)
- 多播负载: "本机使用多播协议从同一子网上的其他 CCU 获取和更新信息。因此,建议使用可支持 IGMP Snooping 功能的路由器。如果 IGMP Snooping 功能不可用, CCU 信息将以广播状态出现在网络上,这将增加同一网络上设备的负载。" (第 20 页)
- Web 菜单的结构: "当本机的菜单锁定开关处于 ON 位置时, 无法使用Web 菜单配置本机。"；"无法显示另一个 VLAN 上的 CCU 单元的信息。" (第 21 页)
- 会话超时: "如果断开与正使用Web菜单访问的CCU的连接30秒, 会出现一个对话框, 并且系统会尝试重新连接。 如果未在30 分钟內重新建立连接,会出现一个对话框, 提示您重新加载。" (第 21 页)
- `<WEB MENU>` N03: "WEB MENU ENABLE、 DISABLE 启用 / 禁用 Web 菜单。"；"PORT LAN-COM 选择连接端口。" (第 80 页)
- N03 SERVICE DISCOVERY: "ON:在 Web 菜单中显示 CCU 列表。OFF:不在 Web 菜单中显示 CCU 列表。… 设为 OFF 时,本机无法由同一子网上其他 CCU 的服务发现功能检测到。" (第 80 页)
- CCU 信息列表: "如果在 30 秒内未收到来自 CCU 的通信, 则相应的CCU 行将变为灰色。"；"CCU 信息列表显示支持的模式为 HDCU3100 V2.2 和更高版本、 HDCU3170 V2.2 和更高版本以及 HDCU5000/5500/3500 V1.0 和更高版本。" (第 23 页)

## I — 自述

本卡覆盖 **Web 菜单**这条远程运维通路: `NETWORK` 菜单的 `<WEB MENU>`（N03）与说明书第 20-23 页的"使用 Web 菜单进行设置"整段（访问 5 步、Web 浏览器、Web 菜单结构、设置/信息显示区域、f 按钮、CCU 信息列表）。它**不含** Web 访问所需的 LAN-COM IP 编址（那在 N01，归 `ccu-network-setup`），也不含 ST2110 / NMOS / Ember+ / SNMP / TSL 等协议（N06-N16，归 `ccu-ip-live`）。本卡只解决: **怎么把 Web 菜单打开、怎么连上、连上后能做什么、为什么连不上或改不动**。

**前置条件链**是四步、且缺一不可（第 20 页 c15）。①PC 与位于**同一专用网络**上的本机相连；②设备已开机；③`NETWORK` 菜单 `<WEB MENU> t WEB MENU` 设为 `ENABLE`；④取到本机网络设置——方法 A: 设置菜单中 `<IP ADDRESS> t PORT` 设为 `LAN-COM`，菜单屏显示本机 IP 与子网掩码；方法 B: 前面板把 DISP/MENU 控制杆向上按在 DISP 位置 **3 秒钟**，在 CCU 编号显示区滚动显示 IP 与子网掩码；⑤在浏览器中输入本机 IP 地址。`PORT` 固定为 `LAN-COM`（第 80 页）——**Web 菜单走 1G 管理口，不走 HKCU-SFP50 的 LAN1/LAN2**。

**浏览器与分辨率有明确建议**。手册写"**建议使用 Chrome**"，并警告"使用除 Chrome 外的其他网络浏览器，可能会破坏网页菜单的布局，或导致某些功能无法正常运行"（第 20 页）；建议使用 `1000×720` 或更高分辨率的显示器以便正常显示（第 20 页）。这不是硬性禁止，而是兼容性边界——用非 Chrome 出问题时应先换浏览器，而不是判定设备故障。

**菜单锁定开关是一道同时作用于本机与 Web 的写保护**。手册明确: "**当本机的菜单锁定开关处于 ON 位置时, 无法使用Web 菜单配置本机。**"（第 21 页）也就是说，Web 菜单可能"能连上、能看，但改不动"——根因在面板上的菜单锁定开关（第 10 页 m 项，用于锁定前面板菜单操作区域）。此外 Web 菜单**无法显示另一个 VLAN 上的 CCU 单元的信息**（第 21 页），发现范围被限制在同一子网/VLAN 内。

**CCU 信息列表与服务发现（SERVICE DISCOVERY）是一组取舍**。N03 的 `SERVICE DISCOVERY` = `ON` 时在 Web 菜单中显示 CCU 列表；= `OFF` 时不显示列表，且**本机也无法被同一子网上其他 CCU 的服务发现功能检测到**（第 80 页）。手册提示: "如果不需要 CCU 列表,或者您希望尽可能减少网络负载,请将此项设为 OFF"（第 80 页）。列表机制依赖**多播**: 本机用多播协议从同子网其他 CCU 获取和更新信息，因此"建议使用可支持 IGMP Snooping 功能的路由器；如果 IGMP Snooping 功能不可用，CCU 信息将以广播状态出现在网络上，这将增加同一网络上设备的负载"（第 20 页，p39）。列表本身还有两条读法约定: 列表按 CCU 编号排序；**如果 30 秒内未收到来自某 CCU 的通信，则该 CCU 行变为灰色**，检测到更新信息时背景色恢复（第 23 页）。列表支持的型号版本为 HDCU3100 V2.2 及更高、HDCU3170 V2.2 及更高、HDCU5000/5500/3500 V1.0 及更高（第 23 页）。

**会话超时与远程功能**。会话侧: 断开与正使用 Web 菜单访问的 CCU 连接 **30 秒**会出现对话框并尝试重连；若未在 **30 分钟**内重新建立连接，会提示重新加载；仍未建立则连接中止、断开与 CCU 的连接（第 21 页）。功能侧（第 23 页 f 按钮，单击显示上下文菜单）: `CCU File`（等同于 FILE 菜单 `<CCU FILE>` 页功能，可在 PC 与本机间上传/下载 CCU 文件）、`Save Log`（下载日志文件 `log.zip`）、`Version Up`（先在 PC 存好包文件，更新中显示进度屏，完成后**设备自动重启、Web 菜单自动重连**）、`License`（下载 `DEVICE.DAT`、装许可证密钥、查软件许可证状态）、`Information`（软件许可证、版本信息、摄像机诊断信息）、`Reboot`（重启本机）。

## A1 — 书中配置示例

1. **访问 Web 菜单 5 步（第 20 页，c15）** —— 真实书中步骤，即本卡的执行主干: ①按连接示例把装 Web 浏览器的 PC 与同一专用网络上的本机相连；②检查设备是否已打开；③在 NETWORK 菜单确认 `<WEB MENU> t WEB MENU` = `ENABLE`；④用两种方法之一取网络设置（菜单 `<IP ADDRESS> t PORT`=`LAN-COM` 显示 IP/掩码，或前面板 DISP 杆 3 秒显示）；⑤在 Web 浏览器中输入本机 IP 地址。
2. **CCU 信息列表屏幕（第 23 页，c15 关联）** —— 真实画面示例: 按 CCU 编号排序的列表视图；当前访问的 CCU 行不显示切换按钮且背景色与其他行不同；30 秒无通信行变灰；支持型号版本如第 23 页所列。显示该列表需 N03 `SERVICE DISCOVERY` = `ON`。
3. **f 按钮上下文菜单（第 23 页）** —— 真实功能清单: `CCU File` / `Save Log` / `Version Up` / `License` / `Information` / `Reboot`，各功能与对应菜单页等价关系如第 23 页所述。
4. **错误消息显示（第 22 页）** —— 真实界面说明: 图标右上角显示当前错误数，单击可下拉显示错误消息；错误消息也显示在标题中心，多条时以设定间隔交替闪烁。

以下为合成演练（非原书内容）—— 手册未提供带具体 IP 的访问演算，故补一段端到端走查供参照:

- **输入**: PC 与本机同子网、本机 LAN-COM 已配 IP、菜单锁定开关 = OFF、用 Chrome。
- **输出**: N03 `WEB MENU`=`ENABLE`、`PORT`=`LAN-COM`、`SERVICE DISCOVERY`=`ON`（要看列表）→ 取本机 IP → Chrome 输入 IP → 打开 Web 菜单 → 在 CCU 信息列表看到同子网其他 CCU → 用 f 按钮下载 `log.zip`。

## A2 — 未来触发

**情境**：

1. 远程或无监视器场景下要配置本机、监视设置信息。
2. 多机巡检要看同一子网上各 CCU 的前面板信息（CCU 信息列表）。
3. Web 菜单"连上了但改不动"，需要定位写保护来源。
4. 浏览器打开后布局错乱或某些功能不工作。
5. 要下载日志（`log.zip`）、上传/下载 CCU 文件、升级版本或装许可证。

**语言信号**：中文——"Web 菜单 / 浏览器 / Chrome / CCU 列表 / 服务发现 / 远程配置 / 连不上 / 改不动 / 下载日志 / 上传 CCU 文件 / 升级 / 许可证"；英文——"web menu / browser / Chrome / CCU list / service discovery / remote / log download / version up / license"。

**相邻区分**：

- **ccu-network-setup**：本卡管 Web 界面本身（N03 + 第 20-23 页）；彼卡管 Web 访问所需的 LAN-COM IP 与端口编址。取本机 IP 用彼卡 N01。
- **ccu-ip-live**：本卡管 N03 Web 菜单与服务发现；彼卡管 NMOS / Ember+ / SNMP / TSL UMD 协议配置（N06-N16）。
- **ccu-genlock-sync**：本卡不涉同步；远程改同步参数时，界面操作走本卡、参数取值归彼卡。
- **文件与日志卡**：f 按钮的 `CCU File` / `Save Log` 与 FILE 菜单功能等价——界面操作归本卡，文件/日志规则（5 个文件上限、RECALL 不含网络设置、日志 30 天、改日期清空）归彼卡。

## E — 执行步骤

**输入契约**（缺失先问，不猜）：①PC 与本机是否同子网（跨 VLAN 不可见）；②本机 LAN-COM 的 IP/掩码（未知则先按 N01 取）；③菜单锁定开关状态；④浏览器类型；⑤网络是否有 IGMP Snooping；⑥是否需要 CCU 列表（决定 `SERVICE DISCOVERY`）。缺任一 → 先询问。

1. **前置检查（任一不过即停）**：PC 与本机在同一子网、同一专用网络（**跨 VLAN 不可见**）；本机已开机；**菜单锁定开关 = OFF**（ON 时 Web 不能配置本机）。
2. **启用 Web 菜单**（`NETWORK` → `<WEB MENU>` N03）：`WEB MENU` = `ENABLE`；`PORT` = `LAN-COM`；`SERVICE DISCOVERY` = `ON`（要列表）或 `OFF`（减负载，但本机不被同子网其他 CCU 检测到）。
3. **取本机 IP（二选一）**：
   a. N01 `PORT` = `LAN-COM`，菜单显示本机 IP 与子网掩码。
   b. 前面板把 DISP/MENU 控制杆按在 DISP 位置 **3 秒**，CCU 编号显示区滚动显示 LAN COM 的 IP 与掩码（摄像机编号不为 0 时）。
4. **浏览器访问**：用 **Chrome** 输入本机 IP；分辨率建议 `1000×720` 或更高。
5. **判停分支**：
   - 页面乱版 / 功能缺失 → 换 Chrome（ce19）。
   - 连上但改不动 → 查菜单锁定开关是否 ON（ce17）。
   - 列表缺机 → 查 `SERVICE DISCOVERY`（`OFF` 则无列表且本机不被发现，ce31）、是否跨 VLAN（ce18）、是否 30 秒无通信行变灰。
   - 会话中断 → 30 秒内自动重连，30 分钟未成则断开，需重新加载（ce20）。
   - 网络无 IGMP Snooping → 多播变广播、增加全网负载，可评估关 `SERVICE DISCOVERY`（p39）。
6. **远程功能（f 按钮）**：`CCU File`（PC↔本机上传/下载 CCU 文件）；`Save Log`（下载 `log.zip`）；`Version Up`（PC 存包 → 更新 → 自动重启并重连）；`License`（下载 `DEVICE.DAT`、装许可证密钥、查状态）；`Information`（许可证/版本/摄像机诊断）；`Reboot`（重启本机）。

**输出契约**：报告 = Web 可访问性结论（IP / 浏览器 / 菜单锁定开关状态 / 子网）+ N03 设置值（`WEB MENU` / `PORT` / `SERVICE DISCOVERY`）+ 列表是否可用 + 执行的远程操作与结果。数值/字符串**原样保留**。

## B — 边界

- **不要用本卡**：LAN-COM IP / 端口编址与链路速度（→ `ccu-network-setup`）；ST2110 / NMOS / Ember+ / SNMP / TSL 协议（→ `ccu-ip-live`）；同步参数（→ `ccu-genlock-sync`）；CCU 文件与日志的规则（→ 文件与日志卡）。
- **手册警告的失败模式**：①**菜单锁定开关 ON → 无法用 Web 菜单配置本机**（ce17，第 21 页）；②跨 VLAN → 无法显示 CCU 信息（ce18，第 21 页）；③非 Chrome 浏览器 → 布局破坏 / 功能异常（ce19，第 20 页）；④断开 30 秒重连、30 分钟硬超时 → 会话可能已中止，勿误以为"设置已保存"（ce20，第 21 页）；⑤`SERVICE DISCOVERY`=`OFF` → 本机无法被同子网其他 CCU 的服务发现检测到（ce31，第 80 页）；⑥无 IGMP Snooping → 多播变广播，增加全网负载（p39，第 20 页）；⑦接入无安全保护的网络 → 未授权第三方可能访问本装置（ce32，第 94 页）。
- **型号差异**：CCU 信息列表支持型号版本为 HDCU3100 V2.2 及更高、HDCU3170 V2.2 及更高、HDCU5000/5500/3500 V1.0 及更高（第 23 页）——更早版本不在列表内；N03 `PORT` 固定 `LAN-COM`（第 80 页）。Web 菜单与列表走 LAN-COM，**不依赖 HKCU-SFP50**，因此未装 SFP50 的机器也能用 Web 菜单。
- **作者盲点（阶段 0 批判）**：①手册只"建议"用 Chrome，未给兼容浏览器清单或最低版本；②Web 菜单**无登录/鉴权说明**，安全性依赖网络隔离（与 ce32 一致）；③`Version Up` 的包来源与回滚方案未述；④30 分钟超时后的会话状态是否保留未说明；⑤CCU 列表用多播，无 IGMP Snooping 时手册只说"增加负载"，未给量化；⑥Web 菜单与 OSD 菜单可切换，但"本机状态屏幕显示"与"OSD 菜单屏幕"的差异手册未完全展开。
