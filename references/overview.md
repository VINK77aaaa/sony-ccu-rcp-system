# Sony 摄像机控制系统使用说明书合辑 — 全书概览

> 阶段 3 产出（压缩自两书阶段 0 的整书理解文档），供编译器打包为随包概览页。

## 一句话主旨

教工程师与操作者把 Sony 遥控面板 RCP-3500/3501 与摄像机控制单元 HDCU5000/5500/3500 组成一套可用的演播室摄像机控制系统：**面板侧决定"谁控制谁、怎么调"**（组网、控制权仲裁、权限、日常调整、参数资产），**CCU 侧决定"信号怎么进出、怎么同步"**（传输方式、系统格式、输出/返回格式、HDR、同步、网络、诊断）；两侧处在同一条"控制—被控"链的两端，互为前置。

## 二、两书如何咬合（跨书依赖链）

两书不是并列的两本，而是**同一条链的上下游**。合并后的主链：

```
[系统级决策] 选型号 + 装选件（HKCU-FB50/SDI50/SFP50/SM50、HZCU-UHD35/CNFG50/SNMP50）
      │
      ├─ 面板侧 ─ 定 CNS 连接模式（LEGACY/BRIDGE/MCS/PC 控制）→ 配面板 TCP/IP 与 RCP 编号 → 接地
      │                 │
      │                 └─ 改 CNS 后必须重启所有摄像机系统
      │
      └─ 主机侧 ─ 定 CABLE TYPE → 定 SYSTEM / CAMERA FORMAT / FIBER TRANSMIT RATE
                        │
                        └─ 派生 OUTPUT FORMAT1-4 / IP-OUT 与 RETURN FORMAT1-4 / IP-RET（查表，不可自由填）
                              │
                              └─ 定 GENLOCK MODE（HD/SD/NETWORK）→ ST2110 系统强制 NETWORK + PTP
                                    │
                                    └─ 定网络（LAN-COM / LAN1-LAN2 / IP Live / NMOS / SNMP / Ember+）
                                          │
                                          ├─ 面板侧只做「相位微调」与「返回源选择」，作用于主机侧已定的框架内
                                          └─ 观测面：主机侧灯语 + 状态画面 11 页 + DIAGNOSIS / 面板侧灯语 + 状态画面
```

### 咬合点速查（按四个"面"划分）

| 面 | 面板侧（RCP）职责 | 主机侧（CCU）职责 | 咬合规则 |
|---|---|---|---|
| **控制面** | CNS 模式、TCP/IP、RCP 编号、PANEL ACTIVE / PARA / IRIS-MB ACTIVE 仲裁、RCP Assign | CNS MODE、CCU NO、MASTER IP ADDRESS、`RCP/CNU` 接口（CCA-5） | 两侧的 CNS 与编号必须一致且**全系统唯一**；CCU 侧 CNS 只有三模式（无"PC 控制"），MCS 下编号**不允许 A–Z** |
| **信号面** | GenLock Mode / CCU Phase（遥控相位）、Return Settings（选返回源与格式项） | GENLOCK MODE / PTP、OUTPUT FORMAT / RETURN FORMAT 矩阵、HDR / OETF / COLOR SPACE | 格式与同步的**定义权在主机侧**，面板侧只在主机侧给出的取值集合内选择 |
| **资产面** | 场景文件（1-5 直达 + 菜单最多 32）、参考文件、镜头文件、OHB 文件；USB 备份（RCP Config / Network Config 分开） | `CCU FILE`（整机菜单快照，最多 5 个；RECALL 不含 LAN COM 的 IP/子网/网关）、`LOG`（最多 30 天） | 两套资产**对象不同、互不覆盖**；换机恢复须两套都做。面板侧 USB 备份不含主机侧设置，反之亦然 |
| **观测面** | NETWORK / ALARM / CABLE / CAM PW 四组灯语 + 状态画面 + 菜单自诊断 | CABLE ALARM / CABLE CONDITION / NETWORK / ALARM / FAN STOP 灯语 + 状态画面 11 页 + DIAGNOSIS + 错误消息表（`CCU:XXX`） | 同一故障两端都有指示但**粒度不同**：面板侧 CAM PW 不亮可能是主机侧 CABLE ALARM（OPEN/SHORT）触发，主机侧灯语优先查 |

## 三、合辑级核心命题（8 条）

1. **一套系统，两个决策层**：面板侧管"控制关系与权限"，主机侧管"信号与同步"。系统级问题必须先判"面板侧 / 主机侧 / 链路侧"，再进对应能力卡，否则会在错误的一层反复试。
2. **面板侧的四模式 ≠ 主机侧的三模式**：RCP 侧有 LEGACY / BRIDGE / MCS / **PC 控制**；CCU 侧只有 LEGACY / BRIDGE / MCS（MCS MODE 固定显示 CLIENT）。选 PC 控制时主机侧如何对应，两书均未给 → 跨书缺口。
3. **主机侧的信号能力由四个开关共同决定**：`CABLE TYPE` + `FIBER TRANSMIT RATE` + `SYSTEM` + `CAMERA FORMAT`。所有输出/返回格式都不是自由设定，而是这四者的**派生查表结果**（手册 FORMAT 项一律写"请参阅第 54/56/58/63 页"）。
4. **型号能力靠选件扩展，菜单随之显隐**：HDCU3500 装 HKCU-FB50 后等同 HDCU5500；4K 输出需 HZCU-UHD35；IP 需 HKCU-SFP50；单模光纤需 HKCU-SM50；Ember+ / SNMP 需 HZCU-CNFG50 / SNMP50。手册中大量"仅在已安装 … 时才会显示"。**菜单项存在性本身就是选件状态的证据**。
5. **同步来源三选一，且与传输方式绑定**：外部 REFERENCE（HD/SD 黑场 / 10 场 ID）、网络 PTP（ST2059-2，需 HKCU-SFP50）、内部。**ST2110 系统必须用 NETWORK 模式**，此时不需要 REFERENCE IN 外部输入。面板侧的相位调节只在主机侧已锁定的框架内生效。
6. **危险区靠权限管理**：面板侧三层防误操作（工程师模式 + 安全代码 0359 + Page/Item Permission）；主机侧靠菜单锁定开关与"仅显示"项（如 MCS MODE 固定 CLIENT、HDR CONTRAST 仅显示）。
7. **参数资产与日志必须落盘**：面板侧场景/参考/镜头/OHB 文件 + USB 备份；主机侧 `CCU FILE`（5 个，不含网络设置）+ `LOG`（30 天，**改 DATE&TIME 会删除所有日志**）+ 固定 USB 路径 `/MSSONY/PRO/CAMERA/HDCU5000`。
8. **不可逆操作只有两个，必须前置警示**：①改 CNS 模式"需重启所有摄像机系统"；②改 DATE&TIME"会删除本机上存储的所有日志"。

## 四、跨书关键术语

完整对照（含两侧同名/近名术语的差异要点与跨书操作含义）见**同目录的术语表**（glossary.md）第 0 节。最影响操作判断的几条：

| 术语 | 面板侧 | 主机侧 | 操作含义 |
|---|---|---|---|
| **CNS / 连接模式** | 四模式（含 PC 控制） | 三模式（无 PC 控制） | 两侧模式集合不对等，跨书缺口 |
| **CCU 编号** | "1–96、A–Z" | MCS 下仅 `1–96`；LEGACY/BRIDGE 下 `1–96、A–Z` | 编号规划以主机侧取值域为准 |
| **同步** | 只调相位（含 SC Phase） | 定参考源与模式（HD/SD/NETWORK + PTP） | 面板侧是遥控入口，模式由主机侧定 |
| **文件** | 摄像机图像参数（场景/参考/镜头/OHB） | 整机菜单快照（CCU FILE ×5） | 对象不同、互不覆盖 |
| **HDR** | HDR Conversion（作用在摄像机图像） | LIVE HDR / OETF / COLOR SPACE（作用在 CCU 输出） | 两个不同的 HDR 域，同名项不可互推 |
| **供电（摄像机）** | CAM PW 四态灯语 | CAMERA FIBER 供电；CABLE ALARM 亮则**不对摄像机供电** | 跨书排障：先看主机侧灯，再看面板灯 |
| **网络口** | 面板接 LAN 集线器（≤100 m） | 面板接 `LAN-COM`；`LAN 1/2` 是 IP 视频/同步专用 | 手册侧证：自动 IP 仅适用于 LAN COM |
| **Tally** | 红/绿/橙，经 EXT I/O 或 CCU | TSL UMD V5.0（UDP 8900）+ 50 芯 D-sub | 协议与引脚都在主机侧 |

## 五、批判与边界

### 时代 / 版本局限
- 两书均为 **2019 年文档**，支持设备清单止于当时型号（面板侧：HDC-P50/P1、BRC-X1000 等；主机侧：HDC5000/5500、HDC3500/3100、HDC2000 系列）。新设备需查各自连接信息。
- 面板手册提"请使用最新固件"但不含任何固件版本号对照。
- ST2110 / ST2059-2 支持以 **HKCU-SFP50 为前提**；SFP+/SFP28 模块型号（如 OTM-10GSR1）手册明确"请与 Sony 销售或服务代表联系"，**不含完整兼容列表**。

### 立场盲点
- 两书都**假设读者已具备广播系统常识**（同步、Tally、返送、TBC、PsF、SQD/2SI、SDI 分级），不解释概念本身。
- 连接拓扑与接口位置大量依赖**图示**，纯文本提取会丢失布线细节 — 能力卡只保留可文字化的规则（选件 ↔ 菜单项对应、格式表、编号/IP 规则、缆长与接地）。
- 菜单全表是**查阅型**内容，只有"设置值 + 说明"，**没有"现象 → 原因 → 处置"的完整决策树**（面板侧 CABLE 红灯只给"接收电平极低"；主机侧 CABLE ALARM SHORT 只给"过电流流经光纤电缆"）。
- 主机侧选件安装被限定为"只有经过服务培训的合格技术人员才能执行"，手册不提供安装步骤。

### 未被证明 / 需标注的假设
- 面板侧：安全代码 0359 是启用保护的万能入口，遗失自定义代码时的恢复依赖该后门，手册未讨论此安全风险；电解电容 5 年寿命按"每天 8 小时、每月 25 天"推算，其他工况无数据。
- 主机侧："带下划线的格式可根据所连接摄像机的 Live HDR 模式设置在 HDR 和 SDR 之间切换"依赖摄像机侧配合，手册未给完整前置条件；DHCP 的"自动 IP"**仅适用于 LAN COM**，不适用于 HKCU-SFP50 的 LAN1/LAN2（此限制只在 N01 说明里出现一次）；LAN1/LAN2 必须设为相同链路速度，否则"无法正常操作"，无容错说明。

### 最强反对意见（对使用者的自我警示）
两书都是**查阅型文本**，大量价值在"精确参数 / 格式串原样可查"（如 `3840×2160/59.94P/12G`、`1080/59.94P(2×)/3G-A`、`CCA-5 200 m`）。因此：**数值、单位、格式串、页码、代码一律原样回报，禁止改写或换算**；菜单全表类内容适合做参考索引而非执行卡。

## 六、缺口清单（合辑级，不得补造，以边界形式交付）

### 单书缺口
1. **面板侧 · PC 控制模式的面板侧配置步骤**：手册仅给 p6 编址示例，CNS 画面无 PC 控制配置入口 → 需 HZC-RCP5 文档补齐；能力卡只保留决策层。
2. **面板侧 · Full Lock 误启用的解除路径**：原书未给，task-10 的恢复动作无原文支撑，已转待复核。
3. **面板侧 · 灯语"现象 → 原因 → 处置"决策树**：原书只有状态 → 含义；处置能力以"灯语判断 → 指向组网/供电规则组合"形式交付。
4. **面板侧 · 电容寿命仅单一工况口径**（每天 8 小时、每月 25 天），其他工况无换算数据。
5. **面板侧 · 源文本内部张力**（已消解留痕）：File/Maintenance 显示条件（p16 vs p20/28/38/39，消解为需工程师模式）；PIX1/WF1 vs PIX2/WF2 接口名（p49 vs p50/53）。
6. **面板侧 · 备份文件格式兼容性、输错安全代码表现、强制激活后主设备恢复流程**：原书未述，相关单元已带缺失条件标注。
7. **主机侧 · 第 67 页 HFR ↔ BNC Link 编配表**：纯文本列对齐丢失（提取为"4 K 2 × 1 2 G 2 1 6 0 P L i n k - 1"一类乱码），**须回查原 PDF 图形**；task-03 的查表能力在此处依据不完整。
8. **主机侧 · 手册只使用未定义的三个术语**：`PsF`、`SQD / 2SI`、`UHB` — 释义含行业通用知识而非手册原文，引用时须注明来源非手册。
9. **主机侧 · 手册故意留白**：多处"请联系 Sony 维修代表或销售代表"（SFP+ 型号清单、电源电压切换、选件板安装步骤、CABLE ALARM SHORT 处置）→ 已作为能力卡边界，不编造。

### 跨书缝（两书各自都不完整）
- **a. 无统一的"两端编号 ↔ 机位"对照表**：面板侧 RCP 编号对应 MSU 机位选择号，主机侧 CCU NO 受 CNS 模式约束，两书都未给出可交叉查表的完整映射。
- **b. "重启所有摄像机系统"的作用域未定义**：面板侧只写"更改连接模式后需重启所有摄像机系统"，未说明是否含摄像机头与主机侧、以何种顺序重启。
- **c. RCP-3500/3501 的供电来源两书描述不一致**：主机侧把"经 RCP/CNU 接口供电"只归给 RCP-3000/1000 系列，而面板侧另有 EXT I/O（10.5–17 V 直流）与 PoE（IEEE802.3af class 2）。**施工前须以实际机型确认**。
- **d. 错误与权限的两端不对称**：主机侧有完整的 `CCU:XXX` 错误消息表，面板侧没有；面板侧有 Page/Item Permission 权限状态，主机侧没有对应表。跨书排障时"另一端查不到"是常态，不是遗漏。
- **e. 选件 ↔ 能力的映射在每本书里都是单端的**：主机侧详列 HKCU-*/HZCU-* 与菜单显隐的关系，面板侧只提 PoE/CCA-5/固件，两书都不覆盖"某选件对整套系统的能力增量"。
