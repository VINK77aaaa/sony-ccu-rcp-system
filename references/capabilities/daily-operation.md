# 摄像机日常操作（供电后例行流程：自动调整 / 光圈 / 快门 / 增益 / ND-CC 滤镜 / 测试信号）

## R — 原文

（带引号者为原文直接引用；未带引号者为依据 verified 单元整理的原文要点摘录，页码为原文所在页。适用于 RCP-3500/3501，涉及所连摄像机的行为"因所连设备而异"。）

- 自动调整中止灯语："在调节进行期间再次按此按钮将停止自动调节。"（p11，AUTO SETUP 模块）；统一口径：调节中灯亮、完成灯灭、停止后灯闪烁、再按停止闪烁（p10-11，摘录）。适用项目：SKIN DTL AUTO HUE、LEVEL、AWB、ABB。
- AWB 前置："在拍摄白色物体时按下此按钮,将会自动校正色温,以便正确显示物体的白色区域"（p28）。
- ABB 行为：自动调节 R/B 黑色确保镜头闭合时黑色无色彩添加；"根据摄像机型号,也会同时调节 Black Set。当执行此操作时,镜头会暂时闭合"（p29）。
- ND/CC 滤镜控制许可："当本机具有 ND 滤镜的控制许可时,这些按钮指示灯会亮起。如果未亮起,则表示摄像机具有控制许可。按一次顶部按钮或底部按钮,可将控制许可切换到本机。"（p11；CC 滤镜同规则, p12）；无滤镜伺服或无该滤镜时灯不亮且无法切换（p11-12，摘录）。
- 测试信号优先级："当 BARS 按钮亮起时, 系统会优先执行BARS 按钮的功能。如果您选择了 TEST,按下 BARS 按钮将其熄灭即可。"（p10）。
- 光圈/主黑电平许可：光圈和主黑电平仅在 IRIS/MB ACTIVE 灯亮时可调；按下 PANEL ACTIVE 亦会点亮该灯；此状态下 PARA 不可用，仅亮灯面板可操作（p8/p14，摘录）。
- 调节模式：RELATIVE 亮=相对值模式（初始值 1/4，可菜单更改），SENS 旋钮此时不起作用；绝对值模式下 COARSE 定 CLOSE 侧下限、SENS 定 OPEN 侧上限（p14，摘录）。
- 快门/指示灯语义：DEG 亮=显示角度值、DEG 灭=显示数秒快门速度；SLS/SHT/ECS 对应慢速快门/快门/扩展清晰扫描模式（p12，摘录）。滤镜/主增益标准值指示灯：绿=标准状态、琥珀=非标准状态，需先在 Standard Ind 菜单选定标准值否则保持熄灭（p12/p47，摘录）。
- 变焦/对焦归属：Zoom/Focus Active 为 ON 时，"无法在摄像机侧调整变焦 / 对焦"（p42）。

## I — Interpretation

这块能力是"开机之后、进菜单之前"的全部高频操作，本质是一套按钮-指示灯状态机：

1. 先看控制权：PANEL ACTIVE/PARA 亮了才能操作（仲裁细节归多机能力），光圈和主黑电平还有第二层 IRIS/MB ACTIVE 许可。
2. 自动调整（AWB/ABB 直接触发；LEVEL/SKIN DTL AUTO HUE 先选功能再按 START/BREAK）靠灯语报状态：亮=进行中、灭=完成、闪=已停止。AWB 要先对准白色物体，ABB 时镜头会自己闭一下。
3. 手动光圈/快门/增益/滤镜都是"看灯-动手-看读数"：滤镜按钮灯亮才有许可，灯灭按上/下键夺取；RELATIVE 灯决定旋钮刻度能不能当真。
4. 要看信号时记住 BARS 压过 TEST。
5. Zoom/Focus Active 决定变焦对焦归面板还是归机身，ON 时机身操作无效。

所有行为的细节都挂在"所连摄像机型号"上，同一按钮在不同机头上表现可能不同。

## A1 — Application Example

原书未提供本能力的亲历/结果类案例。以下为一条明确标记的**合成演练**（按 p10-14/p28-29 规则可复算，非作者经历）：

- 输入：晨检。面板已可操作；要求依次：①对白墙跑 AWB；②中止一个正在进行的 LEVEL 自动电平；③把 ND 滤镜控制权拿到面板；④监视器想看摄像机 TEST 信号却一直出彩条。
- 执行：①按 AWB→灯亮=进行中→灯灭=完成（先确认画面是白色物体）；②LEVEL 运行中再按 START/BREAK→灯闪烁=已停止→再按一次停止闪烁；③ND 按钮灯灭=许可在摄像机→按一次顶部（或底部）按钮→灯亮=夺取成功，之后上=向前/下=向后换档（按住连续更改）；④见 BARS 灯亮→按 BARS 熄灭→再按 TEST。
- 预期：各步终点状态如上；第③步若夺取后灯仍不亮→命中"无滤镜伺服/无滤镜"例外（ce21），属机型边界非故障。

## A2 — Future Trigger

使用情境：
1. 晨检/开播前例行：对白墙 AWB、跑 ABB、确认光圈/快门/增益/滤镜位置（"每天开机要做哪些检查"/"morning checklist"）。
2. 拍摄中亮度不对：动光圈、切 ND/CC（"画面过曝了"/"太黑了"/"iris/open up"）。
3. 面板/机身抢不到某项控制：滤镜灯不亮、摄像师说机身调焦没反应（"ND 按钮灯不亮"/"camera side focus dead"）。
4. 监视器信号异常：一直出彩条、想切测试信号（"怎么都是彩条"/"bars stuck"/"test signal"）。
5. 自动调整跑一半要停（"AWB 怎么中止"/"abort auto setup"）。

语言信号（中英）：晨检、白平衡 AWB、黑平衡 ABB、自动调整 auto setup、光圈 iris、快门 shutter、增益 gain、ND 滤镜、CC 滤镜、控制许可、夺取 takeover、彩条 BARS、测试信号 TEST、DEG、ECS、变焦对焦 zoom/focus。

与相邻能力的区分（初稿，阶段 3 回填）：
- white-black-balance：手动 RGB 白/黑/闪光平衡旋钮的按序调节与 ABSOLUTE 机制归那边；本卡是 AWB/ABB 按钮、光圈/快门/增益/滤镜/信号这类"日流程"。
- mcs-operations：PANEL ACTIVE/PARA/IRIS-MB 的多面板仲裁归那边；本卡只把"灯亮才能操作"当前提，不解决抢权。
- led-diagnostics：NETWORK/ALARM/CABLE 灯语排障归那边；本卡的灯是操作状态灯不是故障灯。
- paint-adjustment：菜单级图像细参数（ATW Setting、Detail、Knee、Matrix 等）归那边。
- maintenance-correction：Zoom/Focus Active 的菜单位置在 Maintenance>Lens，归属判断在本卡，镜头校正参数归那边。

## E — Execution

输入契约：
- 必需 (a) 要执行的操作清单（AWB/ABB/LEVEL/SKIN DTL AUTO HUE/光圈/快门/增益/ND/CC/测试信号）；(b) 面板当前控制权灯态（PANEL ACTIVE、PARA、IRIS/MB ACTIVE——看不到灯态先要现场确认）；(c) 所连摄像机是否有 ND/CC 滤镜及滤镜伺服——不知道先问，不得猜。
- 条件件：AWB 需现场有白色物体；ABB 期间镜头会暂时闭合，提前告知节目侧。

步骤：
1. 前提判定：PANEL ACTIVE 或 PARA 灯亮方可操作（多机仲裁细节转 mcs-operations，判停）。光圈/主黑电平还需 IRIS/MB ACTIVE 灯亮；该激活态下 PARA 不可用，仅亮灯面板可调（p8/p14）。
2. 自动调整：AWB/ABB 直接按对应按钮；SKIN DTL AUTO HUE、LEVEL 先选功能再按 START/BREAK。判读：灯亮=进行中→灭=完成；中止=运行中再按→灯闪烁=已停止→再按停止闪烁（p10-11）。
3. 光圈：CLOSE 按钮——自动光圈开启时按下→指示变 CLS；自动光圈关闭时按下→光圈关闭但指示不变；再按一次取消并恢复上一光圈值（p10，摘录）。模式分支：RELATIVE 亮=相对值（步进初始 1/4），SENS 无效；绝对值下调上下限先 COARSE（CLOSE 侧）后 SENS（OPEN 侧）（p14）。
4. 快门：按 DEG 灯态读窗口——亮=角度值、灭=数秒速度；SLS/SHT/ECS 灯指当前模式（p12）。档位变更走 Paint>Shutter（参数语义归 paint-adjustment）。
5. ND/CC 滤镜：灯亮→直接上/下换档；灯灭→按一次上或下按钮夺取→灯亮后换档；上=向前、下=向后、按住连续更改（p11-12）。**判停分支**：夺取后灯仍不亮→核对机型是否有滤镜伺服/该滤镜——无硬件时灯不亮且无法切换，停止反复尝试（ce21）。
6. 测试信号：BARS 亮时 TEST 不生效→先按 BARS 熄灭→再选 TEST（p10）。
7. Zoom/Focus 归属：机身侧调不动变焦/对焦→查 Maintenance>Lens>Zoom/Focus 的 Active——ON=面板独占，切 OFF 归还机身（p42）。
8. 状态目检：标准值指示灯绿=标准状态、琥珀=非标准；未亮=未选定标准状态（p12/p47）。

输出契约：每步以"指示灯终态 + 窗口/画面读数"确认后报结果；报告须列出"因所连摄像机而异"项的实测值（如 ABB 是否同时调了 Black Set）。中止类操作报告须含"已停止"闪烁确认。

判停汇总：控制权灯全灭→先去 mcs-operations 取得激活，不在本卡内抢权；滤镜硬件缺失→停止夺取并核对机型（ce21）；ATW 长开且模式不适配出现白平衡漂移→关 ATW 改 AWB 一次性校准+手动微调（ce26；该规避动作为标注推导）。

## B — Boundary

- 反场景：要调 Paint 菜单细参数（Detail/Knee/Matrix/ATW Setting）→ paint-adjustment；面板整体无控制权、多面板抢机位 → mcs-operations；NETWORK/ALARM/CABLE 灯异常排障 → led-diagnostics；镜头/Shading/RPN 校正 → maintenance-correction。
- 失败模式 ce20：刚做完自动调整或读完场景文件后，按"绝对值"手感拧旋钮——系统已自动退回相对值模式，"旋钮指示角度和设定值不匹配"，会拧出意外值；恢复=重按 ABSOLUTE。
- 失败模式 ce21：在无滤镜伺服/无 ND、CC 滤镜的机型上反复按滤镜按钮想夺取许可——灯不亮且无法切换，是机型边界不是故障，别按坏按钮。
- 失败模式 ce26：不适配模式下长时间开 ATW——"根据所用模式,可能会发生错误"（p28-29），白平衡跟着画面内容漂移；规避动作（改 AWB+手动微调）为标注推导。
- 失败模式 ce30：Zoom/Focus Active ON 时摄像师在机身上调焦无效——先查归属再报修，避免伪故障。
- 型号差异（RCP-3500 vs RCP-3501）：IRIS 控制杆、主黑电平调节环/RELATIVE、IRIS 指示灯 360° 为 RCP-3500；IRIS 调节旋钮、主黑电平调节旋钮为 RCP-3501；"主黑电平调节功能在 RCP-3501 上不可用"（p25），其灵敏度设定项在 3501 上不存在（ce37）。
- 覆盖缺口（needs-review）：快门/主增益的参数级操作步骤在验证单元库中仅以指示灯语义与菜单口径承载（task-05 的 A 组候选缺口），具体档位表按所连摄像机菜单现场确认。
- 原书盲点（BOOK_OVERVIEW 批判节）：手册假设读者已具备广播常识，不解释增益/快门/同步概念本身；只有灯语表、无"现象→原因→处置"完整决策树；所有功能"因所连摄像机而异"，固件非最新或设备不在支持清单时功能可能异常（p8 末两条注意）。
